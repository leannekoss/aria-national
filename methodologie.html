Formule du score ARIA

Le score ARIA mesure la priorité de contact d'un élu pour les affaires publiques des industries alimentaires : un élu fortement ancré dans une zone de production IAA ET actif sur les dossiers agricoles est prioritaire.

score_aria = score_eco x (1 + score_impl / 10)

# Score implantation (poids économique de la zone)
score_eco = nb_sites_aria (établissements IAA dans le département)

# Score implication parlementaire
score_impl = 3 x membre_commission_agriculture
+ 2 x membre_mission_egalim
+ 1 x membre_commission_economique
+ 0.5 x taux_participation
